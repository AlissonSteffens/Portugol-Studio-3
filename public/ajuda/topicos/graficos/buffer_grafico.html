Buffer gráfico

Para desenhar um jogo, o programa precisa preparar o cenário, o personagem e outros objetos. Um buffer gráfico é uma área de memória que guarda um desenho. Pense nele como uma folha de papel: você pode desenhar nessa folha antes de mostrar o resultado na janela.

Este guia começa com um desenho parado e chega a uma animação. Você só precisa conhecer variáveis, funções e o laço enquanto. Cada exemplo completo pode ser copiado para um novo programa e executado sem arquivos de imagem.

1. Montar o desenho antes de mostrar

Imagine uma apresentação com várias figuras. Você prepara uma página inteira e depois a mostra para a turma. Se mostrasse a página enquanto ainda estivesse desenhando, as pessoas veriam partes faltando.

Na biblioteca Graficos, o programa desenha primeiro no buffer da janela. A função g.renderizar() apresenta o resultado na tela. Assim, você escolhe quando o quadro está pronto. Um quadro é uma imagem completa da animação em determinado instante.

1. Preparar
Limpar o desenho anterior. 2. Desenhar
Colocar cenário, personagem e texto. 3. Apresentar
Chamar g.renderizar().

Você já usa esse buffer quando chama funções como desenhar_retangulo. Não precisa criar um buffer extra para fazer seu primeiro desenho.

2. Seu primeiro quadro

Exemplo completo: céu e chão

programa
{
    inclua biblioteca Graficos --> g

    funcao inicio()
    {
        g.iniciar_modo_grafico()
        g.definir_dimensoes_janela(640, 360)

        // A cor atual será usada para preencher o fundo.
        g.definir_cor(g.criar_cor(110, 190, 240))
        g.limpar()

        // Primeiro desenhamos; só depois mostramos o quadro.
        g.definir_cor(g.criar_cor(70, 150, 70))
        g.desenhar_retangulo(0, 280, 640, 80, falso, verdadeiro)
        g.renderizar()
    }
}

inclua biblioteca Graficos --> g permite usar o nome curto g. criar_cor combina vermelho, verde e azul, com valores de 0 a 255. limpar() preenche o destino atual com a cor escolhida. No retângulo, os quatro primeiros valores são posição horizontal, posição vertical, largura e altura; falso desativa cantos arredondados e verdadeiro preenche a figura.

A posição (0, 0) fica no canto superior esquerdo. O eixo x cresce para a direita e o eixo y cresce para baixo. As medidas são em pixels, os pequenos pontos que formam uma imagem. Neste exemplo, o chão começa em y = 280.

3. Guardar um desenho para reutilizar

Agora imagine que o cenário tenha centenas de blocos, mas quase nunca mude. Redesenhar todos os blocos a cada quadro repete trabalho. Você pode desenhá-los uma vez em um buffer extra e copiar esse desenho pronto para cada quadro.

As funções criar_buffer, usar_buffer, desenhar_buffer, limpar_buffer e liberar_buffer são extensões desta versão Web. Exemplos com essas funções podem não funcionar no Portugol Studio original em Java.
FunçãoO que faz
criar_buffer(largura, altura)Cria uma folha transparente e retorna um número inteiro que a identifica. As dimensões devem ser positivas.
usar_buffer(id)Escolhe a folha que receberá os próximos desenhos. O número 0 escolhe o buffer da janela.
desenhar_buffer(x, y, id)Copia o desenho da folha identificada por id para o destino atual, na posição indicada.
limpar_buffer(id)Apaga o conteúdo da folha, deixando-a transparente. Preserva seu tamanho e seu identificador.
liberar_buffer(id)Libera a memória de uma folha criada pelo programa. Depois disso, seu identificador não pode mais ser usado.

Em inteiro fundo = g.criar_buffer(640, 360), a variável fundo guarda o identificador da imagem na memória. Ela não contém os pixels nem um nome de arquivo. É como o número de uma gaveta: o número permite encontrar o desenho guardado.

Exemplo completo: preparar e copiar um cenário

programa
{
    inclua biblioteca Graficos --> g

    funcao inicio()
    {
        g.iniciar_modo_grafico()
        g.definir_dimensoes_janela(640, 360)
        inteiro fundo = g.criar_buffer(640, 360)

        // Os próximos desenhos vão para o buffer fundo.
        g.usar_buffer(fundo)
        g.definir_cor(g.criar_cor(110, 190, 240))
        g.limpar()
        g.definir_cor(g.criar_cor(70, 150, 70))
        g.desenhar_retangulo(0, 280, 640, 80, falso, verdadeiro)

        // Volte ao buffer da janela antes de montar o quadro.
        g.usar_buffer(0)
        g.desenhar_buffer(0, 0, fundo)
        g.renderizar()

        // A cópia já apresentada continua na janela.
        g.liberar_buffer(fundo)
    }
}

usar_buffer muda o destino. desenhar_buffer usa uma origem, mas não muda esse destino e não apaga a origem. Por isso, você pode copiar a mesma folha muitas vezes. Não é permitido copiar um buffer para ele mesmo.

renderizar() apresenta o buffer da janela, mesmo se outro buffer estiver selecionado. Para aparecer na tela, um desenho guardado precisa ser copiado para o buffer da janela.

4. Transparência, posição e camadas

Um buffer recém-criado é transparente: nas partes em que você não desenha, o fundo continua aparecendo. Isso permite guardar só um personagem em uma folha pequena e colocá-lo sobre o cenário.

Se você desenha um personagem em (0, 0) dentro de uma folha de 24 por 40 pixels e copia essa folha com g.desenhar_buffer(100, 240, personagem), o canto superior esquerdo do personagem aparece em (100, 240) na janela. As coordenadas dentro da folha são locais; a posição da cópia determina onde ela aparece no destino.

A ordem dos desenhos cria as camadas: desenhe primeiro o cenário, depois o personagem e por último o texto da interface. O que for desenhado depois pode cobrir o que veio antes. Não há uma função especial de camadas nesses exemplos; a ordem das chamadas define a sobreposição.

g.limpar() pinta todo o destino com a cor atual. g.limpar_buffer(id) apaga para transparente. Para uma folha que guarda apenas um personagem, evite pintar o fundo inteiro: isso produziria uma caixa opaca em volta dele.

5. Animar um personagem sem redesenhar o cenário

Uma animação mostra quadros em sequência. Neste exemplo, criamos o cenário e o personagem uma vez, antes do laço. Dentro do laço, mudamos a posição, copiamos as duas folhas e apresentamos o quadro. Pressione Esc para encerrar.

Exemplo completo: personagem andando

programa
{
    inclua biblioteca Graficos --> g
    inclua biblioteca Teclado --> t

    funcao inicio()
    {
        g.iniciar_modo_grafico()
        g.definir_dimensoes_janela(640, 360)
        inteiro fundo = g.criar_buffer(640, 360)
        inteiro personagem = g.criar_buffer(24, 40)

        g.usar_buffer(fundo)
        g.definir_cor(g.criar_cor(110, 190, 240))
        g.limpar()
        g.definir_cor(g.criar_cor(70, 150, 70))
        g.desenhar_retangulo(0, 280, 640, 80, falso, verdadeiro)

        // As áreas não desenhadas permanecem transparentes.
        g.usar_buffer(personagem)
        g.definir_cor(g.criar_cor(240, 190, 140))
        g.desenhar_retangulo(4, 0, 16, 14, falso, verdadeiro)
        g.definir_cor(g.criar_cor(60, 80, 200))
        g.desenhar_retangulo(0, 14, 24, 26, falso, verdadeiro)

        g.usar_buffer(0)
        inteiro x = 0
        enquanto (nao t.tecla_pressionada(t.TECLA_ESC))
        {
            // Copiar o cenário cobre a posição anterior.
            g.desenhar_buffer(0, 0, fundo)
            g.desenhar_buffer(x, 240, personagem)
            g.renderizar()

            x = x + 2
            se (x > 616)
            {
                x = 0
            }
        }

        g.liberar_buffer(personagem)
        g.liberar_buffer(fundo)
    }
}

O personagem tem 40 pixels de altura e fica em y = 240, então seus pés chegam ao chão em 280. O limite horizontal é 640 - 24 = 616, para manter a figura inteira dentro da janela.

O cenário cobre toda a janela e é opaco. Copiá-lo a cada quadro apaga visualmente a posição antiga do personagem. Se seu cenário tiver áreas transparentes ou for menor que a janela, preencha o buffer da janela com g.limpar() antes de copiar as camadas.

Para manter o exemplo simples, o personagem avança dois pixels por quadro. A velocidade pode variar conforme a frequência de atualização da tela. Em um jogo mais elaborado, calcule o movimento pelo tempo decorrido: velocidade em pixels por segundo multiplicada pelo tempo desde o quadro anterior.

6. Quando atualizar e quando liberar

Um buffer guarda os pixels desenhados, não as instruções que os criaram. Se uma variável de cor mudar, o desenho já guardado não muda sozinho. Quando o jogador retirar um bloco, por exemplo, atualize a região do cenário ou redesenhe seu buffer. Depois volte com g.usar_buffer(0) e copie o cenário atualizado.

Crie os buffers antes da repetição e reutilize-os. Criar uma nova folha a cada quadro consome memória e tempo. Quanto maior a largura e a altura, maior o espaço ocupado: dobrar as duas dimensões quadruplica a quantidade de pixels.

Use limpar_buffer quando quiser redesenhar na mesma folha. Use liberar_buffer quando não precisar mais dela. Não libere uma folha que ainda será usada no próximo quadro, nem tente liberar o identificador reservado 0. Ao encerrar a execução, o ambiente também descarta os buffers restantes.

Reutilizar imagens reduz o trabalho repetido de desenho, mas não elimina o custo de cálculos, laços ou imagens muito grandes. Guarde partes que mudam pouco; continue atualizando as partes que realmente mudaram.

7. Problemas comuns

  • A janela ficou vazia: confira se chamou g.renderizar(), se voltou ao destino 0 e se copiou seu buffer para a janela.
  • O personagem deixa rastros: a posição anterior continua desenhada. Refaça o fundo do quadro antes de desenhar a nova posição.
  • Há uma caixa colorida em volta do personagem: você pode ter usado g.limpar() na folha dele. Apague com g.limpar_buffer(personagem) e desenhe apenas a figura.
  • Apaguei a folha, mas a cópia antiga continua na tela: limpar a origem não altera cópias já feitas. Monte e apresente um novo quadro.
  • O cenário recebe desenhos que deveriam estar na janela: faltou g.usar_buffer(0) depois de preparar o cenário.
  • Erro de buffer inexistente: confira se guardou o identificador retornado por criar_buffer e se ainda não chamou liberar_buffer para ele.
  • Erro ao copiar para o próprio buffer: escolha outro destino com usar_buffer antes de copiar a origem.
  • O jogo fica lento ou usa muita memória: confira se os buffers estão sendo criados dentro do laço e se suas dimensões são maiores que o necessário.

8. Experimente por conta própria

  1. Troque a cor do céu no primeiro exemplo. Observe que a cor precisa ser definida antes de limpar.
  2. Acrescente uma árvore ao buffer do cenário da animação, antes do laço.
  3. Copie o mesmo personagem duas vezes, em posições diferentes. Você não precisa criar uma segunda folha.
  4. Troque a posição automática por teclas esquerda e direita usando t.tecla_pressionada e as constantes t.TECLA_SETA_ESQUERDA e t.TECLA_SETA_DIREITA.
  5. Desenhe um texto depois do personagem e depois mova essa chamada para antes do cenário. Compare o resultado para entender a ordem das camadas.

Para consultar parâmetros de outras funções, abra a biblioteca Graficos na ajuda. Os exemplos Blocos 2D e Blocos 3D da biblioteca de exemplos mostram o uso de buffers em jogos maiores.
