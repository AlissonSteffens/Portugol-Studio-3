Ambiente do navegador

A biblioteca Navegador permite que um programa Portugol consulte o ambiente em que está rodando: navegador, sistema operacional, celular ou tablet, recursos de entrada, tamanho da janela e da tela, idioma e estado da rede.

É uma biblioteca exclusiva do Portugol Studio Web. Funciona na IDE, na aba de execução e nos projetos HTML exportados. Programas que a utilizam precisam desta versão Web; a biblioteca não existe no Portugol Studio original em Java.

1. Conheça o ambiente atual

Abra este exemplo no editor e execute. Compare o resultado em um computador e em um celular. Redimensione a janela ou gire o aparelho e execute novamente para observar as dimensões e a orientação.

Conheça seu navegador

programa
{
    inclua biblioteca Navegador --> nav

    /* Esta biblioteca é exclusiva da versão Web.
     * Execute no computador e no celular para comparar os resultados.
     * Gire o aparelho ou redimensione a janela e execute novamente.
     */
    funcao inicio()
    {
        escreva("MEU AMBIENTE DE EXECUÇÃO\n\n")
        escreva("Navegador: ", nav.obter_nome(), "\n")
        escreva("Sistema operacional: ", nav.obter_sistema_operacional(), "\n")
        escreva("Celular: ", nav.eh_celular(), "\n")
        escreva("Tablet: ", nav.eh_tablet(), "\n")
        escreva("Suporta toque: ", nav.suporta_toque(), "\n")
        escreva("Mouse ou apontador preciso: ", nav.possui_mouse(), "\n")
        escreva("Janela: ", nav.largura_janela(), " x ", nav.altura_janela(), " pixels CSS\n")
        escreva("Tela: ", nav.largura_tela(), " x ", nav.altura_tela(), " pixels CSS\n")
        escreva("Densidade de pixels: ", nav.densidade_pixels(), "\n")
        escreva("Orientação da janela: ", nav.obter_orientacao(), "\n")
        escreva("Idioma: ", nav.obter_idioma(), "\n")
        escreva("Rede informada como online: ", nav.esta_online(), "\n\n")

        // Escolha controles pelos recursos, pois computadores também podem ter toque.
        se (nav.suporta_toque())
        {
            escreva("Este ambiente permite oferecer joystick e botões de toque.\n")
        }
        se (nav.possui_mouse())
        {
            escreva("Este ambiente também oferece um apontador preciso.\n")
        }
        se (nav.largura_janela() < 600)
        {
            escreva("A janela é estreita: um layout compacto pode funcionar melhor.\n")
        }
        escreva("\nA identificação de dispositivo e sistema é aproximada.\n")
        escreva("Estar online não garante acesso a um site específico.\n")
    }
}

2. Funções disponíveis

Todas as funções são síncronas e não recebem parâmetros. Na ajuda, busque Navegador para consultar a documentação individual de cada função, com o tipo de retorno.

obter_nome()cadeiaFamília identificada: Chrome, Chromium, Edge, Firefox, Safari, Opera, Samsung Internet ou Desconhecido.

eh_celular()logicoEstimativa de celular. Retorna falso para tablet, computador ou dispositivo não identificado. Não usa a largura da janela.
eh_tablet()logicoEstimativa de tablet, incluindo iPadOS em modo de computador e tablets Android.

3. Adaptar jogos e interfaces

Use suporta_toque() para decidir se deve oferecer controles de toque, como o joystick circular. Use possui_mouse() para oferecer interações com um apontador preciso. Um aparelho híbrido pode permitir as duas formas de jogar ao mesmo tempo.

Use a largura da janela para escolher um layout compacto. Uma janela estreita no computador continua sendo uma janela de computador; ela não transforma eh_celular() em verdadeiro. Da mesma forma, conectar um mouse ao celular não o transforma em computador.

A biblioteca apenas consulta informações. Os controles automáticos de toque da IDE continuam sendo criados a partir das teclas e do uso de Mouse no programa; incluir Navegador, por si só, não cria botões.

As dimensões da janela pertencem à área interna do navegador. Elas não representam o tamanho do canvas nem o espaço disponível dentro do painel gráfico da IDE. As dimensões da tela são medidas separadas. Todas usam pixels CSS, que podem diferir dos pixels físicos do aparelho.

As consultas são atualizadas a cada chamada: se estiver fazendo um jogo que acompanha mudanças de tamanho, consulte as dimensões durante a execução. Ao abrir o gráfico em outra aba, as consultas de janela passam a se referir à aba que exibe o programa. No exemplo acima, cada execução imprime uma fotografia daquele momento.

4. Limites da identificação

Navegadores podem reduzir, ocultar ou alterar a identificação do aparelho. A biblioteca usa as informações públicas de User-Agent Client Hints quando disponíveis e a identificação tradicional quando necessário. Não solicita dados de identificação adicionais ou permissões.

O nome do navegador, o sistema e a classificação celular/tablet são estimativas. Dispositivos não reconhecidos retornam Desconhecido para nome e sistema e falso para as duas classificações. Por isso, prefira testar os recursos necessários ao seu programa, em vez de depender de uma marca de navegador ou sistema.

esta_online() consulta navigator.onLine; uma rede local conectada pode aparecer como online mesmo sem acesso à Internet. Para verificar um endereço, tente a operação desejada com a biblioteca Internet e trate a possibilidade de falha.

Em um ambiente sem janela de navegador, as dimensões retornam 0, a densidade retorna 1.0, o idioma retorna uma cadeia vazia, as consultas lógicas retornam falso e nome, sistema e orientação retornam Desconhecido.
